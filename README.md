# AI Grievance Platform for Bharat 🇮🇳

A unified, AI-powered platform designed to simplify citizen grievance submission, tracking, and resolution across public services in India.

##  Objective
To provide an accessible digital system that allows citizens to report issues using voice, images, or text, while AI automates classification, routing, and visibility for authorities.

##  Repository Structure

- README.md – Project overview
- requirements.md – Product requirements
- design.md – System architecture and technical design
- backend/ – Server-side implementation
- frontend/ – Web interface
- docs/ – Additional documentation

## 🚀 Key Features

- Multimodal grievance input (voice, image, text)
- AI-based classification and routing
- End-to-end grievance tracking
- Community escalation
- Geo-based analytics
